Tap a question to see the start point (the idea the question gives you), the end point (where your answer has to finish) and a chain that links the two.

9 marks: one or two developed chains, both linked to the end point and the context. No conclusion needed. 12 marks: two developed chains, each finishing on the end point, using the case study.

The chains are one route through each question, not the only one. Check the case study or the data in the question before you use them.
